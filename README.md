# phoenixheartstrategy-site

One-page company site for Phoenix Heart Strategy Holdings Corp.
Plain HTML and CSS. No build step and no JavaScript.

## What is in here

| File | What it does |
| --- | --- |
| `index.html` | All the words on the page |
| `styles.css` | Colors, fonts and layout. The ink / ember / bone colors are at the top |
| `fonts/` | The three typefaces, stored here so the page does not call other sites. Each has its license file |
| `favicon.svg` | The small icon in the browser tab |
| `.nojekyll` | Tells GitHub Pages to publish the files as they are |

## See it on your computer

Open `index.html` in a browser. Or, from this folder, run `python3 -m http.server` and visit `http://localhost:8000`.

## Publish it with GitHub Pages

1. Open the repository on GitHub and tap **Settings**.
2. Tap **Pages** in the left menu.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set the branch to **main** and the folder to **/ (root)**, then tap **Save**.
5. Wait a minute or two. The live address is `https://feenix2022.github.io/phoenixheartstrategy-site/`.

## Change the words

Edit `index.html`. Every sentence on the page is in that file. Only use facts that are true and that you can show.

## Connect phoenixheartstrategy.com later

Add only the website records your domain host asks for when you set up GitHub Pages. Do not change the MX records or any other email records. Email for this domain runs on them.
